# Anupriya S - Personal Portfolio

## Project Overview

This project is a responsive personal portfolio website created to showcase my skills, projects, technical interests, and contact information. The portfolio works as a digital résumé and provides an overview of my background as an MCA student and aspiring software developer.

## Objective

The objective of this project is to design and develop a professional, responsive personal portfolio using HTML5 and CSS3. The website presents personal information, technical skills, projects, and contact details in a clean and user-friendly layout.

## Technologies Used

- HTML5
- CSS3

## Features

- Professional hero section with name and role
- Professional profile photo/avatar
- About Me section
- Technical Skills section
- Projects section
- GitHub links for projects
- Contact information
- Email link
- GitHub profile link
- LinkedIn profile link
- Smooth scrolling navigation
- Responsive design for desktop and mobile devices
- CSS Flexbox and Grid layouts
- Consistent colour scheme and typography
