# BrewNest - Premium Coffee Landing Page

## Project Overview

BrewNest is a responsive landing page created for a premium coffee brand. The website presents the brand, its coffee features, story, contact information, and social links in a clean and attractive layout.

## Objective

The objective of this project is to design and develop a visually polished, responsive static landing page using HTML5 and CSS3.

## Technologies Used

* HTML5
* CSS3

## Features

* Sticky navigation bar
* Hero section with headline, description, and call-to-action button
* Attractive coffee-themed hero visual
* Features section with three coffee-related feature cards
* About section describing the BrewNest brand
* Contact section with email information
* Footer with navigation and social links
* Responsive design for desktop and mobile screens
* CSS Grid and Flexbox for layout
* Consistent coffee-themed colour palette
* Clean typography and spacing
* Smooth scrolling between sections

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. The BrewNest landing page will be displayed.

## Responsive Design

The website is designed to work on both desktop and mobile screen sizes. CSS media queries are used to adjust the navigation, content sections, cards, and footer for smaller screens.
